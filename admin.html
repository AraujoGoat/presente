🔑 conexão com o GitHub

Isso é feito uma vez só. O token fica guardado apenas neste aparelho (nunca vai pro site). Sem ele, ninguém consegue alterar nada, nem a Mari.
  1. No GitHub (pelo navegador), abra Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Dê um nome (ex: painel), escolha o prazo (ex: 1 ano) e em Repository access marque Only select repositories e escolha o repositório do presente.
  3. Em Permissions → Repository permissions, ache Contents e coloque Read and write.
  4. Toque em Generate token, copie o código (começa com github_pat_) e cole abaixo.
